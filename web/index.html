Tools

Tools let a local model do things — read files, fetch pages, keep notes. They come from MCP servers: programs that run on this computer with your permissions, so only add ones you trust. Guanaco shows the exact arguments and asks before every call. Tools never work with cloud models.

Documents

Index your own files and Guanaco adds the most relevant passages to your questions (turn on Docs in the message box). Files are embedded by a local model and stored only on this computer. Text files only — code, Markdown, TXT, CSV…; PDFs aren't supported yet.
